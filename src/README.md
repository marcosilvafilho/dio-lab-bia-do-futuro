# Código da Aplicação

Esta pasta contém o código do seu agente financeiro.

## Setup do Ollama

```
# 1 Instalar Ollama (ollama.com)
# Baixar modelo leve
ollama pull llama3.2:1b

```

## Código completo

```
Todo o código-fonte está no arquivo app.py

```

## Como Rodar

```
# Rodar a aplicação
python -m streamlit run src/app.py
```
